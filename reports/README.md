# Experiment results

Run `notebooks/credit_card_fraud_detection.ipynb` from the repository root. The notebook generates:

- `figures/class_distribution.png`
- `figures/model_comparison.png`
- `figures/xgboost_confusion_matrix.png`
- `figures/xgboost_roc_curve.png`
- `figures/xgboost_precision_recall_curve.png`
- `model_comparison.csv`

These outputs are generated locally when the notebook is executed. Commit the resulting plots and CSV after reviewing them if you want them visible in the repository. Do not copy old metrics into a new run's results; record the metrics generated by that run.
